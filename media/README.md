# Media assets

## Demo clips

`videos/` contains six palette-optimized looping GIFs converted from the six animated GIFs on the last slide of `演示动图.pptx`. The source GIFs totaled 88.68 MiB; the optimized GIFs total 50.94 MiB at 480×270 and roughly 8 fps, with reduced frame counts and preserved clip durations. `videos/manifest.json` records the Chinese and English labels, source media names, optimized sizes, frame counts, durations, and loop setting.

## Viewer screenshots

`screenshots/` contains four JPEGs captured from the read-only viewer with headless Chrome at 1600×1000 in the light theme. The data shelf was hidden so the images show only the visualization UI. `screenshots/manifest.json` records captions and source files. The knowledge graph, exploration map, node detail, and achievements views are included.

No author names, host names, account names, internal paths, or credentials appear in these assets.
